# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving authentication bypass, privilege misuse, PAM corruption, symlink or path traversal, unsafe file ownership or permissions, backup tampering, rollback redirection, or command execution.

Use GitHub's private vulnerability reporting feature for this repository. Include the affected commit, a minimal reproduction using disposable paths where possible, impact, required privileges, and a proposed mitigation.

Do not test against another person's Mac or include credentials, biometric information, private paths, PAM contents from managed systems, or other sensitive configuration.

## Supported versions

Security fixes are provided for the latest release and current default branch. This project has not undergone an independent security audit.
